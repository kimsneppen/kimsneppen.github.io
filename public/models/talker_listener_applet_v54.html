Behaviours — roles · adaptation · openness · ego

Behaviour model

T agents always talk; the other N−T always listen (Fig. 1 & 3).
Every encounter: talker with prob. θ, listener with 1−θ (Fig. 2).
Each agent keeps a fixed talk-propensity drawn uniformly from [0,1] (Fig. 3c–d). Press Reset to draw a new population.

Adaptive controls

Self: your own action changes you (talk→θ↑, listen→θ↓ — paper Fig. 4). Neighbors: only the contacted agent changes — pushed to listen→θ↓, asked to talk→θ↑; being contacted always raises activity. Activity contrast kept below f. With f=1 expect many small clusters; larger f makes the network grow together.

Social openness σ (common to both modes)

Probability of contacting a random agent instead of one from memory. σ=1 ⇒ random network.
Ego — identity transmission
When an agent talks (on its own, or because a listener asked it), it writes its own identity into the other's memory only with probability ego. 1 = always (original model), 0 = never.
Fires when a selected agent is remembered by no one. walk: ego steps ±δ (min 0, max 1); off: ego jumps to a new random value. Rate: off · 0.001 · 0.01 · 0.1 · 1.
Only one of Ego, var. ego, Evol. ego is active — whichever was set last. Trouser colour shows ego: blue = 0 → yellow = 1.

Colours

Body colour = talk-propensity. Head reddens with self-memory (normal red when all self).

Layout forces

Within a cluster only (0–80 fine, then 160 · 320 · 800 · 1600), spreading members by connectivity. Distinct clusters repel each other so they sit apart; the cloud is RMS-normalised to always fill & fit the window.
Uniform node–node spacing applied to every pair in a cluster. Increase to push the many connectivity‑1 nodes crowded around a hub apart (10× = default; 1–8 fine, then 12 · 16 · 20 · 40 · 80 · 160).
Repels agents that share the same hub, so the many low-degree neighbours fan out evenly around a high-degree node instead of clumping on one side (0 = off; 0–10 fine, then 15 · 20 · 40 · 80 · 160).
A confining bowl centred on the centre of mass of all agents: every node feels the inward force −dV/dr = −4c·r³. Relaxed overdamped, exactly like the other layout forces. c is given relative to the built-in linear pull measured at the core radius, so c = 1 means the two are equal there and the r³ force takes over further out. 0 = off.

About — paper & abstract

Reference

Krebs, Jakob M., and Kim Sneppen. “Model of talkers and listeners in social networks.” Physical Review E 112.4 (2025): 044312. doi:10.1103/dvmm-9ssz

Abstract

Social media networks reveal highly asymmetric communication patterns, where a minority of individuals dominate speech while the majority primarily listen. Yet, the mechanisms governing the emergence and stability of such roles remain poorly understood. Here, we introduce a minimal agent-based model in which disparities in expression and attention give rise to emergent social structure. Persistent self-referential speech generates local dominance and hierarchical organization, whereas listener attention and memory sustain overall network cohesion. The model uncovers a feedback loop linking speaking activity, attention allocation, and memory, which sets the balance between social integration and fragmentation. Our results predict that greater listening propensity, social openness, and memory capacity promote cohesion and mitigate fragmentation, while excessive hub dominance can be curtailed by ensuring that all individuals engage in at least a minimal fraction of listening.

The Ego button

Ego is an applet extension that is not part of the published model. In the paper a talking agent always writes its own identity into the listener’s memory; here that happens only with probability ego. An agent with ego = 1 always transmits itself (the original model), while an agent with ego = 0 only passes on one of its memories — it spreads attention to others but never promotes itself. The corner button toggles ego between 1 and 0 for everyone without resetting the simulation; var. ego gives each agent a fixed random ego, and Evol. ego lets ego mutate whenever an agent is remembered by no one. Trouser colour shows each agent’s ego (blue = 0 → yellow = 1).
