Globalization in a nutshell — 2D

A two-dimensional, many-product version of the model of Sneppen and Bornholdt [1]. L × L agents sit on a square lattice with periodic boundaries. There are N products, each with three parameters: a start cost Start(i), an economy-of-scale exponent γ(i) and a transport cost β(i). Each agent at r owns money and a list F(r,i) = 1 or 0 of the products it can produce.

The price at which agent r₁ delivers one unit of product i to agent r₂ is

C(r₁,r₂,i) = F(r₁,i) · s(r₁,i)γ(i) + β(i) · |r₁ − r₂|   ( + τ across a border )

Only agents with F(r₁,i) = 1 can deliver, and an agent does not buy from itself. s(r₁,i) = 1 + the number of units of i that r₁ sold in the previous round: a new factory has s = 1 and price 1, and with γ < 0 a large producer sells cheaper (economy of scale). |r₁ − r₂| is the shortest distance on the torus, Euclidean or Manhattan.

One round (length T)

  1. Orders. Each product gets n·L² orders. The ordering agent is drawn with probability proportional to w₀ + the money it earned in the previous round: rich agents place more orders, which enriches their surroundings. The base demand w₀ lets agents without income consume as well.
  2. Sales. An order goes to the agent that delivers at the lowest price C (ties at random); the seller earns one unit of money. Prices are fixed during the round, so every agent buys each product from the same seller all round.
  3. Decisions. After the round each agent compares its income with that of the round before. If it went up or stayed the same, the agent goes on producing what it did. If it declined (or is zero), the agent picks at random one product it does not make yet and has money enough to start, pays Start(i) and opens that factory (s = 1).
  4. add mode: the agent keeps its other factories, and a factory that sold nothing in the round closes. switch mode: the agent closes its weakest factory when it opens the new one, so it changes product.

Initially every agent makes one random product and owns money M₀.

What to look for

Lowering the transport costs (the transport factor multiplies every β, and lower gradually decreases it each round, as in Fig. 2 of [1]) turns many local producers into a few large companies with long deliveries. Products with a strong economy of scale (γ near −1) and cheap transport go global first; products that are costly to ship stay local. Countries with a tariff τ on crossing a border (only one border counts) split the markets into national champions.

Views

Agents: every agent with income is a pie, area ∝ income, with a slice for the sales of each product it makes; the pale background shows the factories that sold nothing. Market: for the selected product, each agent in the colour of the factory it buys from; dots are the factories, size ∝ sales. Sales and Money: log-scale heat maps in the gnuplot palette of the paper's figures. Hover over or tap an agent for its numbers. Below the grid: time series of the number of producers, the largest market share, the mean shipping distance and the fraction of agents with income.
