Model & equations

Trimurti: every node passes through the three cosmic functions — it is created by Brahma, sustained by Vishnu, and finally destroyed by Shiva, who strikes it with his trishula (trident).

Rate versions. Node i has size xi. On the directed network its growth is fed by the nodes that point to it (its input nodes):

dxi/dt = xi·(Σj→i xj)·(1−Σx) − decay·xi

mean field:  dxi/dt = xi·(1−Σx) − decay·xi

Shiva eliminates each node with probability pShiva per timescale τ (rate pShiva/τ per node). Brahma creates new nodes of size Small at rate b/τ (default b = 1). Each new node receives a number of input links drawn from a Poisson distribution with mean k, and independently a Poisson(k) number of output links, with the partners chosen at random. The population self-organizes to ⟨N⟩ ≈ b/pShiva.

Simplified version (discrete). This is the τ → ∞ limit of the network model: between successive Shiva/Brahma events the growth equation has fully relaxed. In each timestep, in this order: (1) all nodes grow to their equilibrium value under

dxi/dt = xi·(Σj→i xj)·(1−Σx),

i.e. the growth flow is integrated until Σx = 1 (nodes without input nodes keep their value); (2) Brahma creates one new node of size Small with Poisson(k) input and Poisson(k) output links; (3) Shiva eliminates every node independently with probability pShiva, giving ⟨N⟩ ≈ 1/pShiva. Switching to the simplified version takes the current population as starting condition.

Shiva’s choice. The total elimination probability is always governed by pShiva — the expected number of kills per update is N·pShiva in every mode. The modes only decide how the victim is selected: Random picks uniformly among all nodes; Winner picks with probability proportional to node size xi; Loser picks with probability proportional to xi−1/4.

Simplified no net. This version removes the network entirely: in each timestep every node is eliminated with probability pShiva (the victim is still drawn according to Shiva’s choice — random, winner or loser), one new node of size Small is added, and all sizes are rescaled so that Σx = 1. This is the neutral collapse-driven model of the reference, where survivors grow only through the rescaling after each collapse.

Preset studies. The buttons on the main display start standard runs, all with random Shiva: Base model is the simplified no-net version (no protection); Net is the simplified network model with no protection; Net protection is the network model with protection σ = 1; Net strategy is Net protection with strategic linking.

Net strategy. Here a new node no longer picks its out-links at random: each of its Poisson(k) outgoing links selects a target with probability proportional to that target’s current population xj, while its incoming links stay uniformly chosen. Pointing at the big nodes is the optimal defensive move, since Mprot = Σk→j xj is then large and Vishnu repels Shiva with high probability. But the same links feed those big nodes — growth is driven by Σj→i xj, so the well-connected giants receive still more input. Self-interested protection therefore generates implicit preferential attachment: the size distribution broadens, the in-degree of the largest nodes grows, and the system trades diversity for the stability of a few dominant nodes.

Possible protection. With σ > 0 the nodes a node points to defend it, and Vishnu takes on his protecting role: he leaves the nodes and stands guard on every link, close to the node he protects (the back of the arrow) and never inside its population sphere, with his size proportional to the radius of the protecting sphere. Each elimination event now proceeds as an attack: Shiva selects a target according to the chosen weight (Random, Winner, Loser) and approaches it; the destruction succeeds only with probability

pdestroy = exp(−Mprot·σ / Small),   Mprot = Σk→j xj

where Mprot is the total population of all nodes protecting the target. Otherwise Vishnu repels Shiva, and Shiva selects a new target and attacks again, until one node is destroyed — so each event still costs exactly one node, but victims are biased toward the unprotected. A node pointing to nothing has Mprot = 0 and is always destroyed when attacked. The slider varies σ logarithmically from 0 through 10−6…0.1 up to 1; since the scale is set by Small, σ ≈ Small/Mprot marks where protection becomes strong.

Role of τ. The timescale τ only matters in the rate versions, where it converts probabilities into rates: Shiva strikes each node with rate pShiva/τ and Brahma creates with rate b/τ, while growth proceeds on its intrinsic timescale set by (1−Σx). Small τ makes collapses frequent relative to growth; large τ lets the population relax between events — and in the limit τ → ∞ one recovers exactly the simplified version, where time is counted in discrete update events and τ (like dt) plays no role.

The diversity D = (Σx)²/Σx² counts the effective number of coexisting nodes. Collapses of dominant nodes release the survivors and launch the characteristic diversity waves.
